# `tm` — Data Model

The entity model (projects, tickets, phases, tasks, log entries, questions, status transitions) is owned and documented by `ai-lib`. `tm` does not duplicate that documentation.

For the full data model specification — entities, columns, relationships, lifecycle rules, ordering, indexes, and status validation — see:

- **Installed copy:** `vendor/ai-toolset/ai-lib/docs/data-model.md`
- **Canonical source:** `ai-lib` repository at `docs/data-model.md`

For `tm`'s own architecture (its adapter layers and the one workflow rule it enforces), see `architecture/architecture.md`.
